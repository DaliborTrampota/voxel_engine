# Blocks

## Overview

The block system has four layers:

1. **`Geometry`** — the mesh shape (faces, AABB). Stored by value in a registry, auto-assigned IDs.
2. **`Block`** / **`VariantBlock`** / **`MultiBlock`** — gameplay definition (solid, rotation, material). Stored by pointer in a registry, you provide the IDs.
3. **`BlockMaterial`** — which texture goes on which face.
4. **`BlockState`** — per-placed-instance mutable state (rotation, custom data).

Block IDs 0–8 are reserved by the engine:

| ID | Meaning |
|----|---------|
| 0 | Air |
| 1 | Multiblock sentinel |
| 2–8 | Reserved |

Start your own block IDs from 9 or higher.

## Geometry

`Geometry` wraps a list of `Face` objects and an `AABB`. The engine provides built-in shapes:

```cpp
Geometry::Cube()            // 1×1×1 cube
Geometry::Cylinder()
Geometry::Box(start, end)   // axis-aligned box
```

You can also build custom geometries from faces:

```cpp
std::vector<engine::Face> faces;
faces.push_back(engine::Face::SquareFace(
    engine::FaceTag::Top,
    glm::vec3(0, 1, 0), glm::vec3(1, 1, 1),
    glm::vec3(0, 1, 0),
    glm::vec2(0, 0),    glm::vec2(1, 1)
));
engine::Geometry myGeo(std::move(faces));
```

Face factory methods:

| Method | Shape |
|--------|-------|
| `Face::SquareFace(tag, start, end, normal, uvStart, uvEnd)` | Quad |
| `Face::RectangleFace(tag, start, end, length, normal, uvStart, uvEnd)` | Rectangle |
| `Face::TriangleFace(tag, p1, p2, p3, uv1, uv2, uv3)` | Triangle |
| `Face::CircleFace(tag, center, r, segments, normal, uvStart, uvEnd)` | Circle |
| `Face::CylinderFace(tag, center, r, h, segments, normal, uvStart, uvEnd)` | Cylinder side |

Each face has a `cullDir` — if the voxel neighbour in that direction is solid, the face is not emitted during mesh generation. Set it with `face.setCull(dir)`.

## Registering Geometries and Blocks

`RegistryManager` provides two global registries:

- **`RegistryManager::Geometries()`** — `Registry<Geometry, ByValue, AutoGeneratedID>`
- **`RegistryManager::Blocks()`** — `Registry<Block, ByPointer, UserProvidedID>`

Geometries are stored by value; the registry assigns IDs automatically. Blocks are stored by pointer (supporting subclasses); you assign the `BlockID`.

```cpp
#include <data/RegistryManager.h>
#include <data/TextureManager.h>
#include <data/TextureLoader.h>

// 1. Load textures (call once before registration)
TextureLoader::loadArray2D(
    TextureManager::Get().blockTextures(),
    "path/to/textures/blocks/"
);

// 2. Register geometries
auto& geos = engine::RegistryManager::Geometries();
geos.add(engine::Geometry::Cube(), "cube");

// 3. Register blocks
auto& blocks = engine::RegistryManager::Blocks();
auto& tex = engine::TextureManager::Get();

blocks.add(
    engine::Block(9, engine::Layers::Opaque, &geos.get("cube"))
        .isSolid(true)
        .material(engine::BlockMaterial()
            .add(engine::FaceTag::All, tex.texture("dirt"))
        ),
    "dirt"
);

blocks.add(
    engine::Block(10, engine::Layers::Opaque, &geos.get("cube"))
        .isSolid(true)
        .material(engine::BlockMaterial()
            .add(engine::FaceTag::Top,    tex.texture("grass_top"))
            .add(engine::FaceTag::Bottom, tex.texture("dirt"))
            .add(engine::FaceTag::Side,   tex.texture("grass_side"))
        ),
    "grass"
);
```

### FaceTag Reference

| Tag | Faces affected |
|-----|---------------|
| `FaceTag::All` | All faces |
| `FaceTag::Side` | Front, Right, Back, Left |
| `FaceTag::Front` / `Right` / `Back` / `Left` | Individual horizontal face |
| `FaceTag::Top` / `Bottom` | Vertical faces |
| `FaceTag::Tag1` … `Tag8` | Custom tags for non-cube geometries |

### Block Builder Options

```cpp
engine::Block(id, layer, geometry)
    .isSolid(true)             // participates in collision and face-culling
    .isVoxel(true)             // treated as a full voxel for culling purposes
    .facingUp(true)            // base orientation is +Y (vs −Z for most blocks)
    .rotationMode(mode)        // see Rotation Modes below
    .material(blockMaterial);
```

### Rotation Modes

| Mode | Description |
|------|-------------|
| `RotationMode::None` | No rotation (stone, dirt, etc.) |
| `RotationMode::AxisYSnap` | Snaps to Y-axis multiples of 90° (e.g. furnaces) |
| `RotationMode::AxisXYZSnap` | Snaps to any axis-aligned direction |
| `RotationMode::AxisAngleXYZSnap` | Any axis-aligned direction + Y-axis angle when pointing up/down |
| `RotationMode::AxisAlign` | Column blocks — +X and −X look identical |
| `RotationMode::AxisY` / `AxisXYZ` | Free rotation (not snapped), for special cases |

## Variant Blocks

A `VariantBlock` changes its geometry based on the block IDs of its six neighbours. Useful for pipes, fences, wire connections — anything that visually connects to adjacent blocks.

```cpp
#include <block/VariantBlock.h>

auto& geos = engine::RegistryManager::Geometries();

auto pipe = engine::VariantBlock(
    11,                              // BlockID
    engine::Layers::Opaque,
    &geos.get("pipe_center"),        // base geometry
    engine::RotationMode::None,
    4                                // max number of simultaneous variants
)
.allowMultiple(true)                 // render multiple variants at once
.alwaysUseBaseGeometry(true)         // always include the base geometry

.addVariant(geos.get("pipe_north"), {
    { engine::Side::North, { blocks.get("pipe")->getID() } }
})
.addVariant(geos.get("pipe_south"), {
    { engine::Side::South, { blocks.get("pipe")->getID() } }
});
```

`Condition` fields:
- `direction` — which neighbour to check (`Side::North/South/East/West/Up/Down`)
- `blockIDs` — list of acceptable block IDs in that direction
- `requiredFacings` — optional list of facing vectors the neighbour must have

## Custom Block Behaviour

Subclass `Block` to hook into placement, destruction, and interaction:

```cpp
class MyBlock : public engine::Block {
public:
    using Block::Block;

    void onPlaced(const engine::BlockSetContext& ctx) const override {
        // ctx gives you access to the world and position
    }

    void onDestroyed(const engine::BlockSetContext& ctx) const override {}

    bool onInteract(engine::InteractContext* ctx) const override {
        // return true to consume the interaction
        return false;
    }
};
```

## Layers

The `Layer` enum is passed to `Block` and controls which render pass the block participates in:

| Layer | When to use |
|-------|-------------|
| `Layers::Opaque` | Normal solid blocks |
| `Layers::Transparent` | Glass, water, leaves |

## Looking Up Blocks at Runtime

```cpp
const engine::Block* b = engine::RegistryManager::Blocks().get("grass");
engine::BlockID id      = engine::RegistryManager::Blocks().idOf("grass");
```
